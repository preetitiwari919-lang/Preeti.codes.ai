PREETI TIWARI - SCHOOL SUCCESS / CODING EDUCATION PROJECT PORTFOLIO

WHAT IS INCLUDED
1. index.html - portfolio home page
2. catch-the-star.html - interactive browser game demonstrating events, variables, timing and random movement
3. coding-quiz.html - multiple-choice quiz with scoring and feedback
4. lesson-builder.html - rule-based lesson outline generator (not an AI model)

HOW TO VIEW
- Extract the ZIP file.
- Open index.html in Chrome, Safari or Edge.
- Click each project card to try the project.
- Internet access is not required.

HOW TO PUT IT ONLINE FOR A RECRUITER
1. Create a GitHub account at https://github.com/
2. Create a new public repository, for example: preeti-education-projects
3. Upload all four files (keep them together in the repository root).
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /(root), then Save.
7. Wait for GitHub Pages to publish. Your site link will look like:
   https://YOUR-GITHUB-USERNAME.github.io/preeti-education-projects/
8. Test the link in a private/incognito browser before sharing it.

HOW TO DESCRIBE THESE HONESTLY IN AN INTERVIEW
These are portfolio demonstration projects prepared to showcase practical understanding of beginner coding concepts and educational activity design. Do not say they were previously used with students or developed for an employer unless that is true.
You can say:
"I prepared a small portfolio of browser-based learning demonstrations. The game shows events, variables and game logic; the quiz provides instant feedback on coding fundamentals; and the lesson builder creates a structured activity outline using simple rules. I can explain the code and how I would use each activity to support teacher training."

TECHNICAL NOTES
- Built with HTML, CSS and vanilla JavaScript.
- No external libraries or paid services.
- The lesson builder is rule-based and is NOT connected to an AI service.
